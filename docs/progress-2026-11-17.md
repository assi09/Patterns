## Results, and which can be quoted as final accuracy

A result is **final** when it comes from questions or cases nothing was changed for after they were
seen. A **development** result comes from a set we read and then fixed the agent against: it shows
the fixes work, not how good the agent is on new questions. A **regression** check reruns a fixed
set to show nothing broke.

### How to say it in the report

- Lead with the final results: PHIA batch 2 (97.0%, and the comparison with the baselines), the
  router (98.7%), food matching (22 / 25), RAG (0.94 recall@3, with its caveat).
- Report the verifier as a component test that shows what it catches and that it rejects nothing
  true, not as an accuracy score.
- Say plainly that a one-line pandas expression beats every language system at pure arithmetic
  (99.7%), and what Patterns does that it does not: answers in words, checks every claim, handles
  every other kind of question.
- Times in PHIA batches 1 and 2 include the grader's reading call and are not compared.
