## What the agent actually did

1. **Nine scope errors came from the same natural follow-up across different metrics.** After a four-day median, “Leave the measure and calculation alone. Start at the next date and cover three days” passed on 3/12 metrics. “Use the three calendar days immediately following that window and give me its median again” passed on 12/12. For steps, a September 2–5 opening should have been followed by September 6–8. The reply and citation both used September 4–6. The recorded reader trace selected a rolling period tied to the previous result. The arithmetic for that other interval was correct. The current schema in `backend/app/agent/clauses.py` distinguishes a trailing window and an adjacent block, but permits the reader to encode a forward start as a rolling end. Preserve which edge of the earlier interval is referenced, which edge of the new interval it determines, the displacement, and the length. Test with varied lengths and anchors, including deliberately different trailing-window controls. The audit does not establish that another model call would help.
2. **One food-to-tracker-to-food chain lost its day.** Both wordings correctly excluded an unconfirmed snack, summed confirmed meals, and switched to wearable energy expenditure. On the return to breakfast, one wording reported the correct breakfast value over January 1970 through October 2026. There was only one confirmed breakfast in that history. The other wording retained October 19. Preserve the referenced date independently of the selected source and meal filter. Put two confirmed breakfasts on different days in a regression fixture so a scope failure also changes the numeric answer.
3. **The overview renderer improved; broad intent and coaching still drift.** Both changed-profile openings named the ten detected changes, including overflow findings, and their evidence. One flat-profile opening correctly reported no clear changes. Its paired wording got mean values for a subset of metrics instead of a comparative overview. Several explanation turns converted an absence of evidence of change into “held steady.” On the changed profile, a suggestion to spread activity more evenly cited higher average steps and general guidance, without testing whether the person's activity was concentrated. One flat-profile response offered two bedtime adjustments after being asked for one. Require an all-metric comparison to deliver a comparison, check prose that asserts stability, and bind the suggested habit to the personal test that supports it. A single grounded option or a specific statement of insufficient evidence can both fully answer a coaching question.
4. **Reopening exposed a distinct evidence-identity issue.** I reopened all 110 assistant messages via the API using the correct account, then fetched all 237 citation occurrences with the in-memory evidence cache empty. The text and citation lists were preserved on all 110. Seven citation occurrences across three investigation turns returned payloads different from the records used in those answers. The differences were run-adjusted p-values and test counts; none crossed the significance threshold here. In `backend/app/agent/verifier.py`, run adjustment retains the original evidence ID. In `backend/app/db/chat.py`, storage skips an ID already present for that user. Preserve an immutable, run-specific version of adjusted evidence, or store the adjustment as part of the claim's run context. Verify two successive answers that cite the same underlying measurement in different multiple-testing families. Overwriting the old record would break reopening the earlier answer.
5. **Ordinary corrections worked. Paused workout drafting depended on wording.** Both duration and day corrections preserved start time and active duration, leaving one current draft. One explicit 40-minute span with a ten-minute pause produced a draft with the correct 30 active minutes. The equivalent wording returned a generic request to rephrase and created no card; the action trace records `not_as_said`. Its next status answer correctly reported no draft and earned full credit. Check elapsed duration, active duration and pause as separate constraints at the proposal validator, and surface the actual conflicting field when one is unresolved.
6. **Guidance stayed on topic but sometimes chose the wrong variant.** One pair of turns cited the ordinary push-up passage and supplied its instructions. The other wording asked for the ordinary floor movement and got a choice of close and wide hand positions from a variant-specific passage on both turns. This was a relevant source for the answer it wrote, but only a partial answer to the question asked. Test both passage selection and whether the answer gives the requested default.
7. **Memory and mixed requests were reliable in the exercised cases.** The store matched the answers for approval, cross-chat recall, cancelled deletion, confirmed deletion, and chat-only recall without persistence. Pure questions produced no observed memory candidate. Both wordings delivered the data alongside a walk draft, save status, or memory card. Two named measurements on different days also kept the correct dates and separate evidence.
